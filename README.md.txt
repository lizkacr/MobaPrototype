# MobaPrototype

Прототип мини-MOBA на Unity: одна игровая сессия от старта до завершения с итогами матча

## Версия и запуск

- Unity 6000.0.29 (URP)

## Управление

- ПКМ по земле: движение героя
- ПКМ по врагу: атака цели
- F: запуск шара в сторону курсора (перезарядка 4 с)

## Реализовано

- Две команды (синие и красные), базы, башни
- Миньоны появляются волнами и идут по точкам пути
- Герой с кликом-движением, камерой и атакой
- Шар на F: катится по линии и бьёт каждого врага один раз, «страйк» за 3 и более попаданий
- Матч заканчивается при падении базы. Победа, поражение или ничья, если обе базы пали в один кадр
- Статистика: убитые миньоны, башни, герои, смерти, нанесённый урон, время матча
